# 一百天祝福页

普通网页，谁拿到链接都能打开、能写，不用登录。
数据存在 Supabase，页面放在 Cloudflare Pages，两边都用免费额度，几十个人写完全够用。

## 文件

| 文件 | 干什么的 |
|---|---|
| `index.html` | 来宾看到的页面：上面写，下面直接能看到大家写的 |
| `admin.html` | 你自己用：写第一封、藏信删信、切换要不要先审、导出备份 |
| `config.js` | **只改这个**：Supabase 地址和 key、标题、问题、时区 |
| `setup.sql` | 在 Supabase 里跑一次，把表和规则建好 |
| `api.js` `style.css` | 两个页面共用的，不用动 |

## 怎么上线（大概 15 分钟）

1. **建数据库**
   - supabase.com 新建一个项目（别跟你同步备份的那个混用）
   - 左边 SQL Editor，把 `setup.sql` 整段粘进去
   - 改最下面一处：管理口令，然后 Run
2. **填 config.js**
   - Project Settings → API，抄 Project URL 和 anon / publishable key
   - 千万别填 service_role / secret 那个
   - 顺手把小标签、标题、副标题、问题改成你想要的
   - 有主图就压成 webp 放进这个文件夹，名字填进 `HERO_IMAGE`
3. **放上网**
   - dash.cloudflare.com → Workers & Pages → 创建 → Pages → 上传资产
   - 把整个 `wishes` 文件夹拖进去，会给你一个 `xxx.pages.dev` 的链接
4. **先自己走一遍**
   - 打开 `链接/admin.html`，输口令，写你自己那第一封
   - 用手机、无痕窗口、**微信里**各打开一次首页，写一封试试
   - 换一台没打开过的设备看计数有没有变，变了才算真写进去了
   - 回管理页把测试的那几封删掉
5. **发出去**：一个个私发，带一句"我在替她收一百天祝福，愿意的话留一句就好"

## 已经做好的防护

- 前端那个 key 碰不到表，只能调几个固定的函数
- 来宾只能写新的、看显示中的，不能改、不能删，也看不到被你藏起来的
- 同一个人 10 分钟最多 3 封，整页 10 分钟最多 60 封
- 正文最多 150 字（页面上卡 120），名字 20 字，存进去的字不会被当成代码执行
- 新写的默认直接显示；管理页能把任何一封藏起来或删掉
- 怕有人乱写，就在管理页把"新写的直接显示"关掉，之后写的要你点了才出现
- 管理口令只存哈希，输错一次要等一秒

## 备份

管理页右上角两个按钮：
- **导出 JSON**：全部信，原始数据
- **导出静态页**：只含显示中的信，图和样式都打包在一个 html 里，不连数据库也能打开，可以自己存着或者单独发给她

隔几天导一次，纪念日当天再导一次。

## 可能的坑

- `pages.dev` 和 `supabase.co` 在国内网络下有时候慢或者打不开，微信里尤其要试。打不开就绑一个自己的域名，或者最后只发导出的静态页
- Supabase 免费项目一周没人访问会暂停，去控制台点一下就能恢复；收信那段时间每隔几天自己打开一次就行
